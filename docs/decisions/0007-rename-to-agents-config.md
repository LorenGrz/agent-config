# 0007 — Rename agent-config to agents-config

## Context

The project was called `agent-config`, but it installs into the local `~/.agents/` directory.
The singular name did not match, which made the repo, the plugin, and the paths harder to
connect.

## Decision

Rename everything from `agent-config` to `agents-config`: the GitHub repo
(`LorenGrz/agent-config` -> `LorenGrz/agents-config`), the plugin and marketplace names, the
docs, and the setup skill (`meta/agent-config-setup` -> `meta/agents-config-setup`).

- GitHub redirects the old repo URLs, so existing clones and links keep working.
- The plugin identifier changes from `agent-config@agent-config` to
  `agents-config@agents-config`.
- `install.sh` stays backward compatible: it migrates `~/.config/agent-config` to
  `~/.config/agents-config`, accepts the old `generated by agent-config install.sh` marker
  (so old generated files are regenerated, not backed up), and still reads
  `AGENT_CONFIG_STATE_DIR` and exports `AGENT_CONFIG_HOME` alongside the new names.
- `meta/roadmap-coach/scripts/update-stage.sh` falls back to the old profile path.

## Consequences

- Anyone who installed the plugin under the old name must reinstall it (breaking).
- Existing `install.sh` installs upgrade in place with no manual steps.
- The legacy names remain in the compat code and can be dropped in a later cleanup.
